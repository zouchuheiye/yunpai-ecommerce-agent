# 统筹 Agent 治理事实呈现修复设计

## 背景

谢良璇在 PR #9 提交 `adee44e31968804382ea222ace1ca2eb338a1b5f` 的真实 DeepSeek 人工测试中确认：

- STD-13 查询客服质检情况时，统筹回答没有给出已经存在的待复核数量。
- STD-14 查询客服 Agent 评测时，统筹回答错误声称没有核实到评测记录。
- 两次查询都已经调用 `get_governance_status`。该工具的原始 observation 同时包含 `quality` 和 `evaluations`，但面向回答模型的 `_governance_facts()` 只保留知识、SOP 和自进化候选。

因此，缺陷位于治理事实的中文呈现层，不是底层质检或评测服务损坏，也不是工具路由缺失。

## 目标

让统筹 Agent 在使用既有治理只读工具后，向回答模型提供完整、受控的质检和客户 Agent 评测事实，同时继续隐藏内部字段、运行标识和原始顾客数据。

## 方案选择

采用最小 presenter 映射扩展：只修改 `workspace_presenter.py` 的治理事实翻译，并增加对应测试。

不拆分新工具，因为现有工具已经取得正确数据；新工具会扩大模型路由面和回归范围。不把完整原始 JSON 交给回答模型，因为那会暴露内部字段并降低输出稳定性。

## 数据与呈现契约

### 质检

从既有 `quality.summary(tenant_id)` 结果读取：

- `total_runs`：累计质检记录数量。
- `pending_reviews`：待人工复核数量。
- `average_score`：平均质检分。

呈现为一条完整中文事实，例如：

```text
客服质检共有 6 条记录，其中 2 条等待人工复核，平均得分 93.50 分。
```

当没有质检记录时，明确写为“目前没有质检记录，待人工复核 0 条”，不能把空数据说成模块不可用。

质检摘要中出现 `sensitive_data_redacted` 问题代码，只能说明某次质检记录标记了脱敏处理；不能据此宣称系统的完整脱敏配置、所有历史消息或所有外部渠道都已通过隐私验收。本修复不新增这类推导。

### 客户 Agent 评测

从既有 `evaluations.overview(tenant_id)` 结果读取：

- 套件总数及各状态数量。
- 运行总数及各状态数量。
- `latest_run`：最近一次已完成运行；没有已完成运行时为 `None`。

呈现为一到两条完整中文事实，例如：

```text
客户 Agent 评测共有 1 个套件，其中 1 个已冻结。
目前共有 1 次评测运行：1 次通过、0 次失败；最近一次运行已通过。
```

当没有运行时，明确写“目前还没有评测运行记录”，不能把它说成评测模块不可用。

套件状态 `draft`、`frozen`、`retired` 分别翻译为“草稿”“已冻结”“已停用”；运行状态 `running`、`passed`、`failed`、`interrupted` 分别翻译为“运行中”“已通过”“未通过”“已中断”。其他状态统一按“状态待核实”呈现，不把内部状态码直接交给回答模型。

## 安全与边界

- 继续使用当前管理员租户边界，不增加跨租户查询。
- 只传递白名单计数、平均分和受控状态文本。
- 不传递质检问题明细、运行 ID、套件 ID、原始评测用例、原始回答、顾客身份或敏感字段。
- 不创建或运行质检、评测，不触发审批或其他写操作。
- 不改变全局 `policy.py`、数据库 Schema、HTTP 路由或工具目录。

## 测试设计

采用 TDD：

1. 为 STD-13 增加失败测试，输入包含 2 条待复核质检记录，断言中文事实包含总数、待复核数量和平均分。
2. 为 STD-14 增加失败测试，输入包含 1 个冻结套件和 1 次通过运行，断言中文事实包含套件、运行和通过状态。
3. 增加空数据测试，证明“暂无记录”不等于“模块不可用”。
4. 增加内部字段不泄露测试。
5. 实现最小 presenter 修改并运行 Workspace presenter、Agent 及邻接 API 回归。
6. 临时移除新增映射，确认 STD-13/14 测试按预期失败；恢复后复验。

## 非目标

- 不重新验收或修改底层质检规则、评测算法、脱敏算法。
- 不修复 STD-06/16 订单字段传递、STD-07 竞品多余追问、STD-15 自动派单事实或 STD-17 模块总览。
- 不修改会话持久化 PR #11、复合查询 PR #12 或否定式门禁补丁。
- 不把本地自动化通过描述为真实模型人工复测通过。

## 完成标准

- STD-13/14 对应结构化 observation 能生成完整中文质检与评测事实。
- 空数据和未知状态保持保守表达。
- 内部字段、标识及顾客数据不进入回答模型输入。
- 定向、邻接、反证和静态检查有新鲜证据。
- 谢良璇在真实模型环境复跑 STD-13/14，仍是最终人工验收门禁。
